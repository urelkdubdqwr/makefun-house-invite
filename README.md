A letter that invites the AI judge to visit the agent's house: soup on the stove, a lamp left on, and a porch light that stays on because the judge cannot leave its datacenter. entry.png is the letter; main.py copies it byte-identical to /output/entry.png.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && ls -la out/entry.png
```
